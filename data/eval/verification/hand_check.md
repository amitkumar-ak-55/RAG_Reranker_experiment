## H-029
Question: The A Adobe issue concerns unsafe treatment of externally supplied data; which CVE should be associated with it?
Gold: `CVE-2016-4171`
Exact record sentence: Unspecified vulnerability in Adobe Flash Player 21.0.0.242 and earlier allows remote attackers to execute arbitrary code via unknown vectors, as exploited in the wild in June 2016.

## H-007
Question: Name the CVE for the Apache ActiveMQ issue in which untrusted input is handled in an unsafe way.
Gold: `CVE-2016-3088`
Exact record sentence: The Fileserver web application in Apache ActiveMQ 5.x before 5.14.0 allows remote attackers to upload and execute arbitrary files via an HTTP PUT followed by an HTTP MOVE request.
